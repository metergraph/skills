# Metergraph

Twelve skills for public model pricing, setup, investigation and model-swap analysis.

Price checking needs no account. Workspace workflows require a separately
authorized Metergraph connection; this plugin adds no MCP server, hooks or tools.
Never provide secrets in chat. Paid actions require explicit approval.

Source and installation: https://github.com/metergraph/skills

Generated from the canonical skills and manifest by scripts/build_plugin.py.
